# Estándar de comunicación de este repo

Cuando generes contenido de cara a una audiencia (posts de LinkedIn, videos/pitch, READMEs,
explicaciones a líderes o clientes, entrevistas, cartas), sigue SIEMPRE el playbook completo en
`memoria/21-comunicacion-con-impacto.md`. Reglas mínimas no negociables:

- **Valor primero:** nunca "publicar por publicar". Cada pieza debe dejar algo útil al lector.
- **Hook en la primera línea / primeros 8-12s.** Nunca abrir con "Hola, soy…" ni definiciones.
- **Explica lo técnico con analogías** (técnica de Feynman) y divulgación progresiva:
  propósito → mecánica → detalle. Ancla cada tecnicismo a un "por qué".
- **Historia con tensión** (problema → complicación → resolución), no listas de features.
- **Una sola idea y un solo CTA** por pieza. Escribe para el oído; frases cortas.
- **Honestidad:** solo afirmaciones defendibles; cifras reales; nada inflado por IA.

Para trabajo de GitHub/portafolio, aplica además `memoria/22-estrategia-github.md`
(qué evalúa un reclutador, cómo mostrar valor sin exponer código privado, y no publicar secretos/PII).
